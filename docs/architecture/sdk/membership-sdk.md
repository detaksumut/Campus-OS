# Membership SDK Catalog

The Membership SDK exposes strictly Read-Only Projection DTOs.

| Interface | Purpose |
|-----------|---------|
| `IMembershipLookup` | Basic status lookup |
| `IMembershipVerification` | Check if a member is verified |
| `IMembershipTierLookup` | Retrieve active tier details and benefits |
| `IMembershipCardLookup` | Generate dynamic digital card details |
| `IDirectoryQuery` | Search and filter the Directory Projections |
