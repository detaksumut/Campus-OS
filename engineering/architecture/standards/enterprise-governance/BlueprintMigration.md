# Blueprint Migration Guide

This document defines how existing bounded contexts migrate to newer Blueprint versions.

## Migrating from v0.9 (Draft) to v1.0 (Frozen)
- **Action Required**: Add `CertificationDependencyMatrix.json` and `EvidenceCompleteness.json` to your domain documentation.
- **Action Required**: Ensure all layers conform to the updated `ArchitectureGovernancePolicy.md`.
