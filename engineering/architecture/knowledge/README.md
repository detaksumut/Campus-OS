# Enterprise Architecture Knowledge Base

This directory serves as the definitive central repository for all enterprise-wide architectural wisdom in Campus OS.

- **Decisions/**: Global Architecture Decision Records (ADRs).
- **Patterns/**: Recommended enterprise patterns (e.g., Saga, Outbox, CQRS).
- **AntiPatterns/**: Documented anti-patterns that developers must avoid.
- **ReferenceImplementations/**: Golden standard examples of implemented features.
- **LessonsLearned/**: Post-mortem reports and strategic insights.
