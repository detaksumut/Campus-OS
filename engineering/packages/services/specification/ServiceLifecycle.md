# Service Lifecycle

Shared Services follow the standard Campus OS Maturity Level lifecycle:

1. **Scaffolded**: Generated by the CLI.
2. **Validated**: Passed static analysis and linting.
3. **Tested**: Achieved 100% test coverage.
4. **Certified**: Passed the Campus Certification Engine.
5. **Production Ready**: Successfully integrated with the SDK and tested in the Runtime Simulator.
6. **Released**: Deployed to the platform registry.
