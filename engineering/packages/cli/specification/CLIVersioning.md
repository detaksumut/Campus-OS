# CLI Versioning Policy

Follows strict Semantic Versioning (SemVer 2.0).

- **MAJOR**: Breaking changes to the CLI arguments or breaking changes to the generated Domain template architecture that require a `campus upgrade` migration path.
- **MINOR**: New commands (e.g., `campus new something-new`) or non-breaking additions to the templates.
- **PATCH**: Bugfixes in the CLI execution logic or minor fixes to the IAM template generator.
